## 迭代记录（自我考核驱动的循环）

**迭代 1（分队算法）**：抽检发现 SigLIP 聚类按景别分簇（一致性 0.519）→ 主路改 HSV 颜色特征
聚类 → 复检 **0.9777** ✅（详见验收报告）。

**迭代 2（零人工训练 players_e4_v1）**：E4' 标签 → 1276/141 帧时序切分（ignore 类作背景）→
v8s@1280 微调 30ep。训练验证：player-red mAP50 **0.937**、player-blue **0.935**、referee 0.537。
行为抽检暴露两点：
- 1080P 300 帧：场内框 100%（场内过滤生效），10.7 框/帧，红 5.5 + 蓝 4.8 + 裁判 0.4——构成合理；
- 但颜色一致性仅 **0.739**（框级）/0.833（轨迹级）——低于聚类生产路径，**判定：不替换生产路径**。
  教训：验证集与训练标签同源（自动标签），mAP 高 ≠ 真值准确；行为级独立通道抽检必须做。

**迭代 3（方向，未能在窗口内完成）**：用已验收的 HSV 聚类结果（97.8% 一致性）反向清洗 E4'
标签——只保留"聚类队伍与 HSV 判色一致"的框再训练，预期消除标签噪声主项；另可把 E4' 的
9,039 个 ignore 框改为显式 spectator 类训练（比背景抑制更稳）。
