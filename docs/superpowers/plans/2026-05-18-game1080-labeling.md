# 1080p 比赛数据标注 + P2 训练 实现计划

> **面向 AI 代理的工作者：** 步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从 1080p/60fps 比赛视频标注 200 帧飞盘，加入训练集，训练 P2 模型，消除域间偏差。

**架构：** 提取帧 → `yololabeler` 标注 → 合并训练集 → 训练 P2 → 在 60s 独立片段上测试（非训练段）。

**技术栈：** Python 3, ffmpeg, yololabeler, YOLOv8-P2, PyTorch

---

## 文件结构

| 文件 | 操作 | 职责 |
|------|------|------|
| `data/datasets/game1080/frames/` | 新建 | 提取的 200 帧 JPEG（90min 的后 89min 段） |
| `data/datasets/game1080/labels/` | 新建 | YOLO 格式标注 TXT |
| `data/datasets/frisbee_merged/images/train_game/` | 新建 | 合并到训练集的 1080p 帧 |
| `data/datasets/frisbee_merged/labels/train_game/` | 新建 | 对应的标注 |

---

### 关键：训练/测试无交叠

| 用途 | 来源 | 时长 |
|------|------|:----:|
| **训练标注帧** | 90min 视频的 **60s-90min** 段 | ~89min |
| **测试视频** | `videoplayback_first60s.mp4`（前 60s） | **60s** |

两者来自同一场比赛但**不同的时间段**。模型训练时从未看过 60s 片段的内容。

---

### 任务 1：提取 200 训练帧（从 60s 之后）

**文件：**
- 创建：`data/datasets/game1080/frames/`

- [ ] **创建目录并提取帧**

```bash
mkdir -p data/datasets/game1080/frames data/datasets/game1080/labels

# 从 90min 视频的第 60s 之后均匀采样 ~200 帧
ffmpeg -ss 60 -i movie/videoplayback_trimmed.mp4 \
  -vf "select='not(mod(n,1589))'" -vsync vfr \
  data/datasets/game1080/frames/frame_%04d.jpg
```

计算：60s 后 ≈ 5294s ≈ 317000 帧 ÷ 200 = 1585 帧间隔。用 1589 取整。

- [ ] **Commit**

```bash
git add data/datasets/game1080/frames/
git commit -m "data: extract 200 training frames from 90min 1080p video (>60s)"
```

---

### 任务 2：用 yololabeler 标注（用户手动执行）

- [ ] **运行 yololabeler**

```bash
yololabeler data/datasets/game1080/frames/
```

快捷键：
| 操作 | 键 |
|------|:--:|
| 画框 | W → 拖拽鼠标 |
| 下一帧 | D |
| 上一帧 | A |
| 保存 | S |
| 撤销 | Ctrl+Z |

> **注意：** yololabeler 默认在图像同目录输出 `.txt` 标签。标注完成后需要手动移到 `labels/` 目录。

- [ ] **移动标签到 labels/ 目录**

```bash
mv data/datasets/game1080/frames/*.txt data/datasets/game1080/labels/ 2>/dev/null
echo "Labels: $(ls data/datasets/game1080/labels/*.txt 2>/dev/null | wc -l)"
echo "Has frisbee: $(grep -l '^0 ' data/datasets/game1080/labels/*.txt 2>/dev/null | wc -l)"
```

---

### 任务 3：合并到训练集

- [ ] **复制帧和标签到训练集**

```bash
mkdir -p data/datasets/frisbee_merged/images/train_game \
         data/datasets/frisbee_merged/labels/train_game
cp data/datasets/game1080/frames/*.jpg \
   data/datasets/frisbee_merged/images/train_game/
cp data/datasets/game1080/labels/*.txt \
   data/datasets/frisbee_merged/labels/train_game/
```

- [ ] **更新 YAML 配置**

修改 `configs/frisbee_merged.yaml`：

```yaml
path: /mnt/e/frisbee-detector/data/datasets/frisbee_merged
train:
  - images/train
  - images/train_game
val: images/val
test: images/test
nc: 1
names: [frisbee]
```

- [ ] **Commit**

```bash
git add data/datasets/frisbee_merged/images/train_game/ \
      data/datasets/frisbee_merged/labels/train_game/ \
      configs/frisbee_merged.yaml
git commit -m "data: merge 1080p game labeled frames into training set"
```

---

### 任务 4：训练 P2 模型

- [ ] **确认当前分支**

```bash
git branch --show-current
```
预期：`feat/p2-detector`

- [ ] **启动训练**

```bash
tmux new-session -d -s p2game -c $PWD
tmux send-keys -t p2game "python3 models/train.py \
  --model yolov8s-p2.yaml \
  --data configs/frisbee_merged.yaml \
  --box 5 --name frisbee_det_p2_game_v1 \
  --workers 2 --imgsz 640" Enter
```

- [ ] **监控**

```bash
tmux attach -t p2game
```

- [ ] **训练完成后验证**

```bash
python3 models/train.py --validate-only \
  --model-path runs/detect/frisbee_det_p2_game_v1/weights/best.pt \
  --data configs/frisbee_merged.yaml
```
