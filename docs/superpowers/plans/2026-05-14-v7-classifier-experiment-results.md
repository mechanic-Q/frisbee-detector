# v7 二分类器实验记录

> 2026-05-14 — 用 200 张标注裁剪图训练 ResNet18 二分类器来自动估计 v7_quick FP 率，结果全部裁剪图被判定为 FP（99.8%）。

## 背景

v7 数据驱动精度改进方案基于一个假设：用 bbox 级 hard negatives（裁剪图）替换训练集中的通用背景图片，能更精准地抑制 FP。设计文档见 `docs/superpowers/specs/2026-05-14-v7-data-driven-precision-design.md`。之前的 cls 调参路线（v5/v6/v6b）已确认失败。

v7_quick（imgsz=640, 30 epochs）产出：
| 视频 | 帧检测率 | dets/帧 | vs v3 |
|------|:-------:|:-------:|:-----:|
| 55-56min | 53.5% | 0.86 | 69.9%/1.86 |
| 20-23min | 46.8% | 0.67 | 61.4%/1.28 |

~24% 的一致下降，与 640→1280 分辨率差异吻合。

v7_quick 在两个测试视频上共产生 **4228 个检测裁剪图**（55-56min 1291 个 + 20-23min 2937 个）。

## VLM 快速 FP 估算

用 GLM-4V-Flash 对 100 张采样裁剪图分类："Is the main object in this image a frisbee?"。

结果：**74% TP, 26% FP**。但用户确认 VLM 把白帽子、人头、反光物体大量误判为飞盘，实际 FP 率"远比 20% 多"。VLM 不可信。

## 二分类器方案

### 训练数据

已有的 200 张手动标注裁剪图（来自 v3 审核，`tools/review_web.py`）：
- 22 TP （飞盘）
- 178 FP （白帽子、人头、反光椅子、记分板、身体）

### 训练

`tools/train_frisbee_classifier.py` — ResNet18 预训练权重，差分学习率（fc lr=1e-3, backbone lr=1e-4），类别权重（TP 权重 = 178/22 ≈ 8），过采样（每 batch TP/FP 各半）。

```
Epoch  5/50  train_acc=0.9926 val_acc=0.9268  (best so far)
Epoch 10/50  train_acc=0.9963 val_acc=0.9268
Epoch 28/50  train_acc=1.0000 val_acc=0.9512  (best overall)
Epoch 50/50  train_acc=1.0000 val_acc=0.9512
```

### 验证集评估

val set 41 张（5 TP + 36 FP），95.1% 准确率。但 36/41 是 FP，全标 FP 就有 88% 准确率——验证指标有误导性。

### 推理结果

用训练好的分类器推理 v7_quick 全部 4228 个检测裁剪图：

| 视频 | 分类器判 TP | 分类器判 FP | 估算 FP 率 |
|------|:----------:|:----------:|:----------:|
| 55-56min | 3 | 1288 | **99.8%** |
| 20-23min | 0 | 2937 | **100%** |

所有 FP 置信度 > 0.99。模型极度自信地认为所有裁剪图都不是飞盘。

### 根因分析

1. **22 TP 样本严重不足**：ResNet18 在 22 个正样本上无法学到泛化的"飞盘"特征
2. **严重过拟合**：train_acc=1.0 但 val_loss 从第 5 epoch 后持续上升（0.3 → 1.25）
3. **验证集误导**：41 样本中 36 个 FP，基线 88%
4. **训练/推理分布差异**：分类器训练于 v3 检测裁剪图，但推理于 v7_quick 检测裁剪图——两者分布不同

## 结论

**二分类器方案失败。** 200 张标注数据（22 TP）不足以训练一个泛化的飞盘/非飞盘分类器。该路线的根本假设——"从已有标注中训练分类器来估计 FP 率"——在正样本极度稀少时站不住脚。
