  教训：验证集与训练标签同源（自动标签），mAP 高 ≠ 真值准确；行为级独立通道抽检必须做。

### 迭代 3 结果（players_e4_v2，18:35）

- 验证 mAP50：red 0.943 / blue 0.928 / **spectator 0.815（显式类生效）** / referee 0.485。
- 行为抽检（1080P 300 帧 + HSV 独立判色）：**0.778 框级 / 0.875 轨迹级**——较 v1（0.739/0.833）
  提升但未过 0.90 门，**判定：仍不替换生产路径（HSV 聚类 97.8%）**。
- 错配诊断：抽检三帧零错配 → 不一致集中在远景/切镜段边缘小框（长尾），属检测置信度边缘问题，
  非系统性队伍翻转。
- 复用资产：帧映射公式（f_N=(N−151)×60，哈希验证）、clean_players_labels.py 清洗管线、
  四类数据集 players_e4_clean——下一轮可直接换更大 backbone（v8m@1536）或提高 min_height 过滤。

队员/队伍识别的生产判定继续使用：零样本 person 检测 + BoT-SORT + HSV 颜色特征聚类
（97.77%/97.35%）。players_e4_v2 及其数据链作为资产保留，待下轮迭代达标后切换。

### 迭代 4 结果（players_e4_v3 = v8m@1536，18:5x）

- 验证 mAP50：red 0.928 / blue 0.940 / spectator 0.782 / referee 0.553——与 v2（v8s@1280）基本持平。
- 行为抽检（1080P 300帧）：**0.783 框级 / 0.846 轨迹级**，vs v2 的 0.778/0.875——无实质提升。
- **结论：backbone 规模与输入分辨率不是一致性瓶颈**。剩余错配来自自动标签本身的系统性噪声
  （清洗只能去掉"与聚类冲突"的部分，保留下来的框仍以自动标签为真值训练，上限受聚类质量约束）。
- **三轮迭代结论（v1 0.739 → v2 0.778 → v3 0.783）**：检测器路线在零人工前提下收敛于 ~0.78 档，
  无法逼近聚类路径的 0.978。要突破必须引入"人工抽检校准过的金标准小集"（如 30 帧人工核对）
  作为第三通道仲裁——已超出零人工边界，交由用户决策。
- **生产路径最终定案**：零样本 person + BoT-SORT + HSV 聚类（97.77%/97.35%），players_e4 系列权重
  与数据链留作资产（若未来接受小规模人工核对，可直接续训）。
