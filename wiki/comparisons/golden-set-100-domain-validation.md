# 金标准 100 帧域外验证（含方法论失败修正）

## TL;DR

在真实转播画面（1080P 决赛视频）上做 9 模型对比，**自动金标准判据失败**，
排名绝对数字不可信；但实验产出了更有价值的东西：**完整的域外误检类型清单**，
它直接给出了训练数据的缺口方向。

## 实验设计

- 视频：2024 城市飞盘俱乐部锦标赛决赛（1080P/47min/30fps）
- 采样：100 帧 = 50 全局均匀 + 50 检测导向（全片 1fps 扫描 2833 帧，1991 帧有检测命中）
- 9 个候选：D-FINE-S / RF-DETR-S / prod-v8sP2 / shadow_v1 / v8s / 11s / 26s / ctrl-v8sP2 / prod@640
- 推理：低阈值保存全部检测，离线扫阈值

## 方法论失败：自动判据无法构建金标准

三层递进的自动判据**全部失效**：

| 判据 | 假设 | 失败原因 |
|---|---|---|
| ① 多模型共识（≥3） | 共识 = 真目标 | **同源相关性误检**：8 个 YOLO 系在同一数据上训练（含相同 494 硬负样本），在相同物体上犯相同错误 |
| ② 场地投影过滤 | 真盘在场内 | 标定 json 只在标定帧（118500）附近有效，其他帧镜头已摇移 |
| ③ 外观特征（白度+圆度） | 真盘是白色圆盘 | **白帽子同样白色圆形**，无法区分 |

人工巡检 210 个"共识框"裁剪（4 板 × 64 格）后的判定：**真飞盘约占 40-45%**，
其余为误检。因此基于它的 mAP 排名（D-FINE 0.659 / prod 0.638 / ...）**绝对数字作废**。

## 真正有价值的产出：域外误检类型清单

人工判定 210 个高共识误检，归类（按频次）：

| 误检类型 | 典型外观 | 为什么骗过模型 | 负样本对策 |
|---|---|---|---|
| **白帽子**（最多 ~40%） | 白色圆顶+帽檐 | 与飞盘同为白色圆形、尺寸相近 | 收集白帽子 bbox 负样本 |
| **黄色场地锥/标记** | 黄色小三角/圆点 | 高饱和小目标 | 黄色标记负样本 |
| **记分牌绿色装饰** | 赛会 logo 绿斑 | 高对比小色块 | 记分牌区域负样本 |
| **橙色运动鞋** | 橙红小目标 | 小目标+饱和色 | 鞋类负样本 |
| **白色车身/帐篷** | 白色大色块 | 白色+低纹理 | 尺寸过滤部分有效 |

**核心洞察**：模型不是"没学好飞盘"，而是**没人教过它们这些不该看的东西**。
与 [[hard-negative-mining]] 一致（负样本迭代曾把误检压 55%），
但负面清单需**扩展到"非草地场景物体"**——白帽子、场地器材、记分牌。

## 修正后的建议

1. **不采信本次自动指标**；模型选型暂沿用 [[detector-architecture-benchmark-v2]] 的 test 结论（D-FINE 领先），
   但需在**人工标注金标准**上复核
2. **优先做负样本扩展**（按上表清单）：预计比换架构更能提升真实域表现
3. **金标准正确构建方式**：人工标注 100 帧（含负帧），现成 `tools/review_desktop.py` + yololabeler 可用
4. **事件统计瓶颈定位**：上游飞盘检测在真实域仍有大量误检，**先解决检测，再谈事件**

## 方法论教训（存入知识库）

- **同源模型共识 ≠ 真值**：模型共享训练数据时，共识只反映共同偏差
- **test 集排名不可外推**：RF-DETR 从 test 第 2 到域外靠后，是过拟合信号
- **无独立验证通道时，宁可不给指标**：报告"白帽子误检"这类定性发现，
  比给一个建立在污染 GT 上的假精确 mAP 更有价值
