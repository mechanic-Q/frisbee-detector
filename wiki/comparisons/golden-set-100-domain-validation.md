# 金标准 100 帧域外验证

## 动机

[[detector-architecture-benchmark-v2]] 的 476 图 test 集是 640×480 roboflow/COCO 素材，
无法反映 1080P 真实转播画面的表现（历史观察到 shadow_v1 在 1080P 上误检严重）。
本验证在**真实比赛视频**上做域外评测。

## 协议

- **视频**：2024 城市飞盘俱乐部锦标赛决赛（1080P/47min/30fps）
- **采样**：100 帧 = 50 全局均匀 + 50 检测导向（1fps 全片扫描 1991/2833 帧有检测命中）
- **金标准**：候选并集（9 模型，分层入口阈值 YOLO 0.10 / DETR 0.30）中 **≥3 模型共识 + conf≥0.3 + 尺寸合理** 的框 → 159 框 / 86 帧
- **人工验证**：高共识框裁剪网格目检（72 格）确认判据；9 模型全共识框经裁剪确认几乎全为真飞盘
- **VLM 通道不可用**（GLM API key 已按安全要求清理），改用共识度分层 + 人工目检作为独立通道

## 结果（GT = 159 框）

|---|---|---|---|---|---|
| dfine_s | 0.6593 | 0.5078 | 0.673 @0.3 | 30.1 | 640 |
| prod_v8s_p2 | 0.6381 | 0.3986 | 0.598 @0.15 | 93.9 | 1280 |
| prod_v8s_p2_640 | 0.6080 | 0.3808 | 0.620 @0.15 | 159.1 | 640 |
| shadow_v1 | 0.5685 | 0.3675 | 0.570 @0.05 | 91.6 | 1280 |
| yolo_v8s | 0.5357 | 0.3274 | 0.588 @0.2 | 91.6 | 1280 |
| ctrl_v8s_p2 | 0.4969 | 0.3054 | 0.505 @0.15 | 94.0 | 1280 |
| yolo_11s | 0.4343 | 0.2480 | 0.474 @0.15 | 83.6 | 1280 |
| rfdetr_small | 0.3970 | 0.2650 | 0.480 @0.3 | 73.6 | 672 |
| yolo_26s | 0.3019 | 0.1749 | 0.326 @0.1 | 94.2 | 1280 |

## 三条结论

1. **D-FINE-S 域外领先扩大**：test 集领先 prod 3 分 → **域外 2.1 分**（0.659 vs 0.638）；
   mAP50-95 领先 11 分（0.508 vs 0.399）——唯一同时赢精度与定位质量的模型。
2. **RF-DETR 严重掉队**：test 第 2（0.743）→ **域外第 8（0.397）**——过拟合 roboflow 640×480 域。
   **教训：test 集排名不可外推，域外验证是必须的。**
3. **YOLO26s 两处垫底**（test 0.570 / 域外 0.302）——可彻底排除。

## 附带发现

- **9 模型全共识是高质量自动采标信号**（人工裁剪确认），不依赖 VLM 即可扩展金标准集
- 域外最佳 F1 仅 0.33-0.67 → **飞盘检测在真实转播画面上仍是最大提升空间**（这正是事件统计出不来数的上游原因）
- 分辨率：prod 640 (0.608) < 1280 (0.638)，1280 对 1080P 视频有 3 分增益
